Basic Router Configuration
==========================
1. Configure Router Hostname
----------------------------
Router(config)#hostname ABC

2. Configure IP Domain Name
---------------------------
ABC(config)#ip domain-name abc.net

3. Configure Banner Message of the Day (MOTD)
---------------------------------------------
ABC(config)#banner motd #Unauthorized Access Prohibited!#

4. Secure the Privileged EXEC Mode
----------------------------------
ABC(config)#enable password cricket
Saves the password as plain-text in the configuration file. So it is not secured.

ABC(config)#enable secret cricket
Saves the password as encrypted-text in the configuration file. So it is secured.

5. Secure all the ways to access the Router
-------------------------------------------
2 ways to access a router:
a) Physically using console port
b) Remotely using vty port

ABC(config)#line console 0
ABC(config-line)#password football
ABC(config-line)#login
ABC(config-line)#exit

ABC(config)#line vty 0 4
ABC(config-line)#password baseball
ABC(config-line)#login
ABC(config-line)#exit

6. Enable Password Encryption Service
-------------------------------------
ABC(config)#service password-encryption

7. Set Security Password Minimum Length
---------------------------------------
ABC(config)#security passwords min-length 8

8. Enable IPv6 Unicast Routing
------------------------------
ABC(config)#ipv6 unicast-routing

9. Configure IP Addressing
--------------------------
ABC(config)#interface Fa0/0
ABC(config-if)#description Connection to User LAN
ABC(config-if)#ip address 172.16.1.1 255.255.255.0
ABC(config-if)#ipv6 address 2001:211:A:1::1/64
ABC(config-if)#no shutdown
ABC(config-if)#exit

ABC(config)#interface Fa0/1
ABC(config-if)#description Connection to Server LAN
ABC(config-if)#ip address 172.16.2.1 255.255.255.224
ABC(config-if)#ipv6 address 2001:211:A:2::1/64
ABC(config-if)#no shutdown
ABC(config-if)#exit

10. Configure User Database
---------------------------
ABC(config)#username abul secret kabul123
ABC(config)#username kuddus secret boyati123

11. Enable in-band Authentication
--------------------------------
ABC(config)#line console 0
ABC(config-line)#login local
ABC(config-line)#exit
ABC(config)#line vty 0 4
ABC(config-line)#login local
ABC(config-line)#exit

12. Configure SSH
-----------------
ABC(config)#crypto key generate rsa

To view the generated public key:
ABC#show crypto key mypubkey rsa 

To SSH: C:\>ssh -l kuddus 172.16.1.1

To enable SSH only:
ABC(config)#line vty 0 4
ABC(config-line)#transport input ssh
ABC(config-line)#exit

Configure additional SSH Parameters:
ABC(config)#ip ssh version 2
ABC(config)#ip ssh time-out 60
ABC(config)#ip ssh authentication-retries 5

To save the configuration:
ABC#copy running-config startup-config 

ABC#copy running-config tftp:
